# ГДЗ Каталог

Устанавливаемое веб-приложение (PWA): каталог решебников для 3–11 классов
со ссылками на соответствующие страницы [reshak.ru](https://reshak.ru/).

- 522 решебника, 9 классов, 15 предметов (данные с главной страницы reshak.ru);
- фильтр по классу и предмету, поиск по автору/названию, избранное;
- каталог работает без интернета; просмотренные обложки кэшируются;
- сами решения не копируются — карточка открывает страницу на reshak.ru.

## Запуск

Сборка не нужна. Каталог открывается и просто двойным щелчком по `index.html`,
но установка как приложения и офлайн-кэш работают только через сервер (`localhost` или HTTPS):

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

Установка: в Chrome/Edge — кнопка «Установить» в шапке или значок в адресной строке;
на Android — «Добавить на главный экран»; на iOS — «Поделиться» → «На экран “Домой”».
Установка работает на `localhost` и по HTTPS (например, GitHub Pages).

## Обновление каталога

Исходные данные лежат в `tools/raw/<класс>.txt`, по строке на решебник:

```
путь|обложка|годы|ИИ|название|авторы
```

После правок:

```bash
node tools/build.mjs      # пересобирает data/catalog.json
python3 tools/icons.py    # (при необходимости) перерисовывает иконки
```

При изменении файлов приложения увеличьте `VERSION` в `sw.js`.

## Локальные решения

Для учебников из `data/solutions/*.js` карточка открывает решения прямо в приложении
(без перехода на другой сайт, работает офлайн). Сейчас: Макарычев, алгебра 7 класс, № 1–65.

- Решения написаны самостоятельно; условия заданий из учебника не копируются —
  хранится только номер, краткая тема, ответ и объяснение.
- «Режим объяснения» (переключатель на странице учебника) показывает ход рассуждений
  к каждому пункту и правила по теме; без него видны только ответы.
- Новый учебник: добавить файл в `data/solutions/`, подключить его в `index.html`
  и в список `ASSETS` в `sw.js`.
